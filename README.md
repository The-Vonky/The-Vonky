## `> cat engineering.md`

```text
[01] Make data changes traceable.
[02] Prefer versioning over silent overwrite.
[03] Back up before migrations or destructive operations.
[04] Test behavior, not just happy paths.
[05] Let CI block bad changes.
[06] Keep production data, credentials and backups out of Git.
[07] Build for the person who will actually use the software.
```

Things I care about increasingly as my projects grow:

- **auditability and immutable history**;
- **SQLite/PostgreSQL data integrity**;
- **safe migrations, backup and restore**;
- **automated tests and CI gates**;
- **PR-based development and reviewable changes**;
- **clear failure states instead of silent errors**;
- **turning business rules into explicit, testable software rules**.
